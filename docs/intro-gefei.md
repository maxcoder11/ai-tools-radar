# 我做了一个 AI 工具站的情报库，全部开源：15,662 个站的真实流量 + 12 万条 dofollow 外链明细

做 AI 工具站这一个多月，最缺的不是灵感，是**情报**：

- 哪些 AI 站正在起量？（不是听谁说，是看数据）
- 它们靠什么渠道吃饭？SEO 还是社媒还是 AI 引荐？
- 想做外链，去哪发？别瞎找了——看竞品在哪拿的 dofollow，照着投。

市面上没有现成答案。SimilarWeb/Semrush 单查一个站可以，但没人把"全量 AI 工具站"这个切面整理出来。所以我自己攒了一个，今天开源：

**GitHub：https://github.com/ppop123/ai-tools-radar**
**在线版：https://ppop123.github.io/ai-tools-radar/**（GitHub Pages，点开即用）

## 里面有什么

**① 总榜：15,662 个 AI 工具站，按真实流量排**

不是投票、不是编辑推荐。每个站带：月访问量、自然搜索流量、环比增长、全球排名、域名注册时间、dofollow 反链数。点任意一行展开：12 个月流量曲线、流量渠道构成（自然搜索/直接/社媒/AI 引荐各占多少）、头部关键词。

**② 增长榜：谁在起飞**

按流量环比排序。只收有完整 12 月曲线、上月至少 500 访客的站，过滤掉分母太小的假增长。找黑马看这个就够了。

**③ 新品雷达：谁在刚开张**

按域名注册时间排的新站。这周注册、刚被目录收录的 AI 工具都在里面。做竞品监控或者找新赛道，每天刷一眼。

**④ 外链库：这个我最推荐**

两个用法：

- **竞品侦察**：输入竞品域名（比如 janitorai.com），直接列出它的 top100 dofollow 外链来源——哪个页面给的链、什么锚文本、什么平台类型、权重分多少。你要发外链，照着这个清单来，一投一个准
- **全库浏览**：12,000 个真实给 AI 工具站发过 dofollow 的页面（从 94,705 个来源页里筛的），AI 导航站、评测博客、资源页都有，带权重分和平台分类

总榜反链列还有个小 ⬇，直接下载该站 dofollow 明细的 CSV。

## 数据怎么来的（简单说）

收录层：toolify、There's An AI For That、aixploria、futuretools、futurepedia、rundown 六个 AI 目录站全量盘点，去重后 12,774 个独立域。

数据层：SimilarWeb 口径的流量估算（月访/排名/渠道构成/12 月趋势），Semrush 口径的自然搜索数据和 dofollow 外链索引。域名注册时间来自 whois，覆盖 98%。

新鲜度：六个目录每日 diff，新收录的站会自动进雷达。

都是估算值，做方向判断够用，别当精确值引用。

## 怎么用

```bash
git clone https://github.com/ppop123/ai-tools-radar.git
cd ai-tools-radar
python3 -m http.server 8899
```

纯静态零依赖，或者直接开在线版。仓库里有个 AGENTS.md——**把仓库丢给 AI（Claude Code / Kimi / Cursor 都行），它读完自己就能跑起来、改起来**。

这些数据我自己要用，但独吞没意义——做站的人互相卷收录卷排名，情报层越透明，大家越能把时间花在产品上。数据快照会持续更新，欢迎 star / fork / 提 issue。
